# DevSu Bank Test

## Overview

This repository contains a technical test project for the **Fullstack Developer** position at DevSu. The project implements a banking application with both frontend and backend components, demonstrating fullstack development capabilities.

## Project Description

This is a comprehensive banking system test that includes:

- **Frontend**: User interface for banking operations
- **Backend**: RESTful API and business logic for banking services

The project is designed to evaluate fullstack development skills including:
- Frontend development (UI/UX implementation)
- Backend development (API design and implementation)
- Database management
- Integration between frontend and backend
- Code quality and best practices

## Purpose

This test is part of the DevSu recruitment process for the Fullstack Developer role, showcasing the candidate's ability to build complete web applications with modern technologies.
